Built a dynamic program performance tracker and dashboard in Google Sheets/Excel to analyse registrations, attendance, satisfaction, participant sources, volunteer hours, and costs. Used spreadsheet functions, KPIs, dropdown filters and charts to turn program data into clear insights and support data-driven decisions.

# Event Performance Tracker & Decision Dashboard

## Project Overview

I built this **Event Performance Tracker and Dashboard** to show how program data can be collected, analyzed, and turned into useful insights for decision-making.

The dashboard allows users to select a program and instantly review its performance across participation, satisfaction, staffing, and costs.

## Key Questions

This project helps answer questions such as:

* Which programs attract the most registrations?
* How many registered participants actually attend?
* Where are participants hearing about programs?
* Which programs have the highest satisfaction?
* Where are no-shows occurring?
* Are programs staying within budget?
* What is the cost per attendee?
* Which programs may need to be continued, improved, or reviewed?

## Key Metrics

The dashboard tracks and calculates:

* Confirmed registrations
* Total attendance
* Attendance rate
* No-show rate
* Average satisfaction score
* Participant source
* Volunteer hours
* Budgeted vs. actual costs
* Cost per attendee

## Spreadsheet Functions Used

The workbook uses spreadsheet functions to automate calculations and update results when a different program is selected:

* `XLOOKUP` – retrieves details for the selected program
* `COUNTIF` – counts records that meet one condition
* `COUNTIFS` – counts records using multiple conditions, such as program name and attendance status
* `SUM` – calculates totals
* `SUMIF` – totals values for a selected program
* `AVERAGEIF` – calculates average satisfaction scores for a selected program
* `IF` – handles conditions such as zero attendance
* `IFERROR` – prevents formula errors when data is unavailable

## From Data to Decisions

The goal of this project is not just to display numbers, but to support better decisions.

* **High registrations + low attendance** may suggest a need for better reminders or follow-up.

* **High satisfaction + strong attendance** may support continuing or expanding a program.

* **High cost + low attendance** may indicate that spending or program delivery should be reviewed.

* **Strong participant sources** can help identify which outreach methods are most effective.
